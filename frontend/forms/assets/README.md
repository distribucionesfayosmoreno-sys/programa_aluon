# Assets requeridos

Este formulario es **100% HTML/CSS** (sin imagen de fondo). Solo usa un asset raster para el **logo**.

Coloca aquí:

- `logo.png` (logo de ALUON)
- `Nexa-ExtraBold.woff2` (fuente Nexa ExtraBold)
- `ref.jpg` (opcional, solo referencia para calibración; **no se usa** en el HTML)

El HTML referencia estos paths de forma relativa:

- `./assets/logo.png`
- `./assets/Nexa-ExtraBold.woff2`
